# Google Search Console Setup Guide

## 📝 **Google Search Console mein website submit karne ke steps:**

### Step 1: Google Search Console Access
1. https://search.google.com/search-console par jao
2. Google account se login karo
3. "Add Property" click karo

### Step 2: Domain Verify Karo
**Option A - HTML File Method:**
1. Google ek verification file dega
2. Us file ko `client/` folder mein upload karo
3. File accessible honi chahiye: `https://yourdomain.com/google[xxxxx].html`

**Option B - Meta Tag Method:**
1. Google meta tag copy karo
2. `index.html` ke `<head>` section mein paste karo
3. Save karo aur deploy karo

### Step 3: Sitemap Submit Karo
1. Verification ke baad, Google Search Console mein "Sitemaps" section par jao
2. Sitemap URL add karo: `https://yourdomain.com/sitemap.xml`
3. Submit karo

### Step 4: robots.txt Check Karo
- URL: `https://yourdomain.com/robots.txt`
- Check karo ki properly accessible hai
